# Перевірка редактора колекцій 4.0.30

Статус: код і цільові перевірки готові; APK та Samsung S23 Ultra — після окремого погодження. Повний етап 4.1 ще не завершений.

## Перед встановленням

Записати поточну версію й ручний порядок головних колекцій та двох різних настроїв. Оновлювати поверх наявного застосунку, без очищення даних. Перевірити, що ручний порядок зберігся.

## На обох рівнях

1. Довгий тап по обкладинці/назві відкриває редагування з вібровідгуком; звичайний тап поза режимом відкриває колекцію. Кнопка «Упорядкувати» також працює, навіть для однієї підбірки.
2. Тап по назві відкриває поле в плитці. Перевірити 1 і 40 символів, 41 символ, лише пробіли, вставлення кількох рядків. Неприпустима назва не записується. Власна назва не змінює автора.
3. Кнопка клавіатури зберігає назву. Back при відкритій клавіатурі скасовує текст, але залишає режим редагування; наступний Back скасовує незбережений порядок. Уже збережена назва залишається.
4. Після перезапуску збережені назви видно в плитках, заголовках та списках закладок/ротації. Перевірити офлайн із наявним кешем метаданих.
5. «За абеткою» під заголовком показує стандартний порядок: українські назви перед латинськими, «Galaxy 2» перед «Galaxy 10». Зміна видимої назви пересуває плитку в цьому режимі. Порядок підтверджується загальним «Готово»; Back перед підтвердженням його не зберігає.
6. Перетягнути обкладинку з початку в кінець і назад через межі екрана. Поле назви при цьому не відкривається; автопрокрутка плавна. Перерваний жест відновлює порядок і режим. Після ручного порядку перейменування не пересуває плитку.
7. Змінити порядок в одному настрої: інші настрої та головний список незалежні. Загальне «Готово» показує наявні погоджені анімації.
8. Перевірити довгі назви та великий системний шрифт: головна назва до двох рядків, підбірка — один рядок, клавіатура/помилка не перекривають дію редагування.
9. Під час редагування випадковий тап не вмикає ротацію та не змінює закладку. Після виходу вони працюють; налаштування автозміни й склад пулу не змінюються від перейменування.

## Автоматичні перевірки

`node scripts/collection-order.test.cjs`: 31 перевірка збереження, старого ручного порядку, абетки, назв, помилок і відкладеного запису, клавіатурного скасування та автопрокрутки. Native-компоненти й сховище підмінені; реальна клавіатура, жести та плавність потребують телефона. Додатково TypeScript і lint, без Android-збірки.

Особисті назви записуються окремо за стабільним ID; старий формат порядку сумісний. Нові ключі не містять авторських або API-секретів. Для відкату коду можна повернути попередню версію через Git; на телефоні не видаляти застосунок і не очищати дані для обходу заборони downgrade. Підготовку підписаного виправлення з більшим versionCode погоджуємо окремо.
