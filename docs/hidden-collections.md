# Приховані колекції · 4.1.0

## Поведінка

Упорядкувати → рядок «За абеткою», справа наявна SVG-шестерня → Налаштування колекцій → Приховані колекції. Усередині настрою аналогічний шлях відкриває лише його приховані підбірки. Вхід працює й із порожньою сіткою. Нового пункту у футері або загальних налаштуваннях немає.

Око: SVG 18 px / підкладка 28 px / зона 44 px. Неактивна плитка приховується одразу з Undo; активна — після попередження. Останнє джерело: вибрані категорії, пауза або скасування. Поточна встановлена шпалера цим не змінюється.

Приховування батьківського настрою також прибирає його підбірки зі збереженої полиці та ротації. Самі закладки, назви, порядок і улюблені не видаляються. Повернення та Undo відновлюють видимість, але не активують джерело чи автозміну. Окремо приховані підбірки не відновлюються разом із батьківською колекцією.

Метадані прихованих читаються з локального кешу, без запитів Unsplash; за відсутності кешу залишається власна назва або ID і заглушка обкладинки.

## Збереження та ротація

`HiddenCollections.kt` зберігає native-мапу `hiddenCollectionsV1`: стабільний ключ mood:/collection: → IDs підбірок. Приховування й вилучення з `activeCollections` записуються разом під спільним блокуванням із застосуванням шпалер. Native-список activeCollections є джерелом правди для JS; застарілі JS-запити не можуть активувати приховані IDs.

Якщо активні джерела змінилися, старий пул очищується та скидається час його перезбору. Наступний фоновий запуск будує пул з решти джерел або вибраних категорій; при мережевій помилці встановлена шпалера залишається, старий пул не повертається. Спільне фото може знову потрапити з іншого дозволеного джерела — це не блокування фото.

Пауза також встановлює intervalMinutes=0 і pausedByCollectionHide, скасовує розклад. Налаштування враховують цю native-паузу після перезапуску; явний запуск ротації знімає прапорець. Саме повернення його не скидає. Повторна native-перевірка останнього джерела відхиляє застаріле підтвердження.

## Перевірки на S23 Ultra

1. Оновлення поверх 4.0.x: власні назви, ручний порядок, закладки та активні підбірки збережені.
2. На обох рівнях шестерня лише в режимі редагування, справа від абетки; «Готово» прибирає цей рядок. Футер незмінний.
3. Приховати неактивну плитку, натиснути Undo. Повторити та повернути через панель. Перезапуск зберігає приховування.
4. Приховати всі настрої або всі підбірки: Упорядкувати → налаштування залишається доступним, усі записи можна повернути. Великий список прихованих прокручується до кінця.
5. Приховати підбірку окремо, потім її настрій, повернути настрій: підбірка залишається прихованою. Повернути її окремо.
6. Із двох активних підбірок приховати одну: є попередження, лишається друга. Дочекатися наступного тіку — пул з дозволеного джерела.
7. Останнє джерело: Скасувати нічого не змінює; Категорії зберігає розклад; Пауза вимикає автозміну. Перевірити цілий настрій із кількома активними підбірками.
8. Після паузи перезапустити застосунок і телефон: автозміна вимкнена. Повернення джерела не запускає її; явне ввімкнення знову працює.
9. Без мережі приховування/повернення доступні. Після зміни активного джерела стара шпалера залишається, але старі джерела не продовжують ротацію. Повернути мережу, дочекатися фонового повтору.
10. Улюблені фото й приховані фото не змінилися. Повернена закладка знову з’являється на полиці.
11. Регресія 4.0.32: перейменувати останню плитку з клавіатурою, перевірити помилку порожньої назви, закрити клавіатуру, перетягнути й зберегти порядок.

Автоматично пройшли 61 JS і 38 Kotlin-тестів; TypeScript та compileReleaseKotlin. Моки не підтверджують геометрію Android-панелі, реальну ротацію на Samsung чи плавність. APK не збирався.
